# PROJECT_MAP.md — Complete Project Structure & Route Map

## Identity
- **Domain:** anastanveer.com
- **Framework:** Next.js 16 App Router
- **Language:** TypeScript 5.7
- **Styling:** Tailwind CSS v3 + custom CSS (app/globals.css)
- **Animation:** Framer Motion 12 + Lenis 1.3 smooth scroll
- **Icons:** Lucide React
- **Output:** `output: "export"` — 100% static HTML, no Node.js server
- **Build:** 145 static pages pre-rendered at build time
- **Deploy model:** GitHub → static host (Apache via .htaccess)

## Data Flow

```
User request → Static HTML served (no server)
                      ↓
         app/layout.tsx (runs siteJsonLd())
                      ↓
         page.tsx (runs jsonLdForPage(path))
                      ↓
         data/site.ts → content
         data/seo-pages.ts → SEO page config
         data/blogSeo.ts → blog expanded content
                      ↓
         lib/seo.ts → metadata + JSON-LD schema
                      ↓
         components/seo/JsonLd.tsx → <script type="application/ld+json">
```

## Contact Form Flow

```
User fills form → reCAPTCHA v3 token obtained
               → POST /api/contact (FormData)
               → .htaccess rewrites → backend/public/index.php (PHP)
               → PHP validates + sends email
               → Response: { success: true/false }
               → Redirect to /thank-you on success
```
